# 算法与移植说明

## 完整依赖链

- `problem2_gui.py` → `problem2_optimizer.py` → `diameter.py`、`polygon_update.py` → `problem_variables.py`。
- `problem2_parallel.py` 复用同一个优化器，提供案例级和网格级进程并行。
- 外部计算依赖为 NumPy、SciPy；GUI 使用 Python Tkinter Canvas，不依赖浏览器或 Matplotlib。

## 功能与改动

计算核心从当前工作空间复制，保留原有函数接口和数值计算。新增通用启动脚本、安装元数据、单案例 JSON CLI 和小规模验证输入。原 GUI 的“评价指标”与“较优阈值”占用了同一网格行，本次将评价指标移至下一行，恢复两项控件的独立显示。

并行 CLI 自动创建输出父目录，并在存在失败案例时返回非零退出码；不更改几何模型、随机案例生成、进程分配或优化评分。

旧的 100/1000 案例专用脚本依赖特定桌面输入及历史配置，不作为通用入口。其案例并行计算能力由本目录的通用并行模块完整提供；用户可通过 `CaseTask`、`run_cases_parallel` API 输入自有案例。此目录不包含历史原始数据、账号、官方接口配置、运行日志或模拟器程序。

## 数值解释

角度以度输入，代码使用三角函数构造方向向量。目标区域/约束圆通过多边形表示，目标区域与测向扇区求交，区域直径使用旋转卡壳。候选点经过粗网格与局部细化，结果是已评估点集合中的最佳点。

均匀角度采样仅保留非空、非零直径交集；方法一取其最大直径，方法二用 `math.fsum(values) / len(values)` 求平均。无有效角的候选点评分为无穷，搜索时过滤。快速样例使用较粗角度采样，可能跳过较窄的有效角区间；应通过精度敏感性实验验证用于研究的参数。

## 跨平台范围

源码不包含本机绝对路径；启动位置通过 `__file__` 定位。命令行只依赖 Python 和数值库，可用于无界面主机。GUI 需要匹配的 Tcl/Tk、中文字体以及可用的桌面显示。Windows 的 vista 主题不可用时回退到系统默认主题。

本发布为可移植源码，不是携带 Python 的免安装可执行文件。其他操作系统仍需安装自身平台的依赖。实际运行过的平台在 VALIDATION.md 列出，未运行的平台不标记为通过。
