# 问题3绘图代码：已有实验与三阶段流程

仅交付代码。作者未安装依赖、未运行绘图、未编译论文；运行后版面需由使用者检查。
已只读查看实际工作簿的工作表、列名、版本编码和调试记录，并查看已有流程图。

## 软件与依赖

使用 Python 3.10 或更高版本。可以在 VS Code、PyCharm 的终端，或 Anaconda Prompt 中运行。
依赖：pandas（读取与整理逐局数据）、openpyxl（读取xlsx）、numpy（数值计算）、matplotlib（绘图）。不需要 Graphviz、LaTeX 或图像生成服务。

在本目录打开终端，按需安装：

```powershell
python -m pip install -r requirements.txt
```

需要一个中文字体。脚本自动尝试微软雅黑、黑体、思源黑体、苹方、宋体等；找不到会明确报错。也可以指定字体文件。

## 运行

把 `已完成实验汇总与逐局表.xlsx` 复制到脚本所在目录（不改名），然后运行：

```powershell
python plot_q3.py
```

也可以直接指定工作簿完整路径：

```powershell
python plot_q3.py --xlsx "D:\你的目录\已完成实验汇总与逐局表.xlsx"
```

不指定工作簿时读取脚本同目录的工作簿。公开仓库版本不包含个人电脑路径，也不上传工作簿或原始实验日志。

单独绘制三阶段流程图（不需要工作簿）：

```powershell
python plot_q3.py --only flow
```

单独绘制已有实验图：

```powershell
python plot_q3.py --only experiments --xlsx "D:\你的目录\已完成实验汇总与逐局表.xlsx"
```

指定中文字体与输出父目录：

```powershell
python plot_q3.py --only flow --font "C:\Windows\Fonts\msyh.ttc" --out "绘图结果"
```

`--out` 下每次新建带时间戳的子目录，不覆盖之前的图。默认保存在脚本旁的“输出”目录中。

## 输出图与使用口径

每张图输出 PDF、SVG、400 dpi PNG。PDF适合论文插图；SVG可用 Inkscape 等继续编辑，文字未转轮廓，换电脑编辑需要相应字体；PNG适合预览。没有必要把全部图都放入论文。

| 文件前缀 | 图的内容 | 阅读方式 |
| --- | --- | --- |
| 01 | 本地30组的任务时间、移动距离、规划墙钟配对散点 | 横轴未接入、纵轴接入；同图两轴尺度相同，虚线下方代表接入后的数值更小 |
| 02 | 本地逐地图任务时间差 | 按地图种子排序；接入减未接入，负数代表接入后更快 |
| 03 | 官方独立演练的三指标箱线图与逐局点 | 各30局独立案例，不连线、不配对；黑菱形为均值，箱体为25%—75%分位数，横线为中位数；须线为1.5倍四分位距范围内的最远观测，全部记录均以圆点绘出 |
| 04 | 两张调试地图的任务耗时和相对MAIN减少率 | 每种目标数只有一张地图；不加误差条、不推断总体优势 |
| 05 | 六局调试规划墙钟时间 | 使用从0开始的线性纵轴，并标出原值；标注当时并行负载影响 |
| 06 | 初始扫描 → 覆盖与定位 → 清除收尾 | 三个横向主要方框；保留锁定、累计预算、真实反馈、有限网格与进度保存 |

图01和02共同支撑MAIN选型说明；图04和05适合作为初步调试观察；图03适合作为演练补充材料，不能替代三次正式测试成绩。

所有实验图均使用真实逐局记录重新计算绘图数值，未把交接中的四舍五入均值硬编码为图形数据。图04减少率为 `(MAIN - 对照) / MAIN × 100%`。图02相对变化为 `(接入 - 未接入) / 未接入 × 100%`，符号方向不同，图注与CSV列名已分别说明。

生成的CSV保存本地配对差值、各组均值、六局调试数值，便于核对；`绘图来源.json` 保存工作簿路径和SHA256。这些是绘图来源记录，不代表独立核验官方原生日志。

## 数据检查

脚本针对本次已交接工作簿，不包含六版本180局主实验的绘图接口或预留代码。

- 本地两版各30局，按配对ID对齐，检查种子、场景指纹、目标数；种子为20261101—20261130，共395个目标。
- 官方两版各30局，检查60个案例ID和指纹互异、配对ID为空，目标总数分别为395和391。
- 调试仅MAIN/C3/C4在SMOKE_01、SMOKE_02上的6局，目标数分别为10和16。
- 确认完整清除，检查数值字段缺失与非有限值，核对逐局三项均值与Q2对照汇总。

缺失值不补0；发现批次、配对或字段异常会停止，避免静默漏行或混入主实验。成功状态不同的后续批次应另行设计图形，不要删除校验后直接套用。

## 流程图文字对应的完整含义

这是总体流程概述，不是每个分支的完整算法图。阶段二的“累计预算内择优行动”表示比较可执行中间行动与直接到站计划；到站优先扫描，沿途若已经解决本站全部必要任务可以提前结束阶段。阶段内重决策不补充预算。

转入阶段三的条件是全部频道已发现目标或由实际覆盖证据确认无源；预测覆盖不能充当无源证据。阶段三锁定目标进行定位和试清除，达到规定上限或无有效候选才转入有限网格，持续保存搜索进度。每次反馈后优先检查近距离清除需求与任务完成条件，因此已经完成任务时可提前结束，无需机械执行所有阶段。

清除成功必须以真实清除反馈确认，定位区域变小不等于清除成功。该图没有宣称连续全局最优或无条件完成保证。

## 修改外观

脚本顶部 `COLORS` 修改配色，`configure_font()` 修改字号，各绘图函数的 `figsize` 修改宽高，`save()` 修改PNG分辨率。流程图文字集中在 `flowchart()` 的 `titles`、`lines`、`outputs` 中。

运行后请检查中文是否完整、坐标与标签是否重叠，尤其是放入论文双栏或缩小后的字号。PDF采用嵌入字体，SVG保留可编辑文字。原图片和论文均不会被脚本修改。
