# Policy 3 实现与15局验证说明

本次正式验收使用 `configs/balanced.json`：相对默认配置仅将绕路预算从90秒降为45秒（名称字段同步改变），其余算法参数相同。采用单 worker，10个随机混合源场景与5个特殊场景。

结果：**15/15局全清，203/203个目标全部发现并清除**。平均虚拟时间 **9264.739 秒**，平均策略CPU时间 **16.629 秒**，平均模拟器会话墙钟时间 **19.846 秒**。

## 配置选择与复现

先做一局HTTP联调，再在同一合法场景、同一版代码下比较90秒与45秒绕路预算。两者均清除14/14目标；90秒配置虚拟耗时9454.67秒，45秒配置9182.44秒。于是选择45秒配置进行正式15局。该单局预试只用于选择可用初始配置，不构成参数全局最优证明；预试不计入下面15局。

```powershell
python tools/run_acceptance.py --config configs/balanced.json --output results/acceptance_repeat --real-limit 600
```

在policy3目录运行，output须为新目录。环境与策略的完整配置及源代码指纹均保存在结果目录。源码和覆盖资产从开始到结束没有变化：
