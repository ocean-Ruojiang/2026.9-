# Policy 3 实现指南

本文对应 `strategy3` 实际代码，面向编程手和后续编程 agent。数学定义见同目录 `数学说明.md`。当前实现可直接连接相邻目录的自制模拟器，不需要策略端加载任何场景真值。

## 1. 一局执行链路

`__main__.py → runner.run → Coverage + Scheduler + Client`。

1. 加载并校验配置，创建 20 个 UNKNOWN 频道，各自持有任务圆的保守外接多边形。
2. 复核 22 站资产及 1848 个连续方格的覆盖证据，创建每频道独立的负反馈排查账本。
3. `/enter` 后读取服务剩余时间；预留退出时间，开始串行决策循环。
4. `Scheduler.choose(world)` 返回一个原子 `Action`。同点组合可包含最多 3 条操作，但每条之间都提交真实反馈并重新检查剩余队列。
5. 客户端为请求生成唯一 ID；网络重试复用完全相同的 ID 与 JSON 字节。无法确认的请求阻止发送新 ID。
6. `state.commit` 只接受合法且未提交过的响应。更新位置、虚拟时钟、频道历史和覆盖记录；首次正反馈使 UNKNOWN 转 KNOWN。
7. 只要被操作频道仍为 KNOWN，立即 `beliefs.rebuild`，利用全部历史重新推断；随后 `scheduler.observe` 结算预算、更新兜底进度或中断外圈。
8. 完成判据成立后正常 `/exit`；超时、预算实现错误、无可执行动作等均写出不成功摘要，不能按全清完成上报。

## 2. 共享数据结构

`model.py` 定义：

```python
Observation(point, result, bearing=None, request_id="")
Channel(channel, polygon, status="UNKNOWN", history=[], failed_clear=[], ...)
World(channels, position=(0, 0), radio=1, virtual_time=0, actions=0)
Action(point, kind, channel, reason="", score=0, details={})
```

以上列表只是字段示意；真实 dataclass 使用 `default_factory`，没有共享可变默认值。

状态为 UNKNOWN、KNOWN、CLEARED、ABSENT。首次发现后即退出全域频道搜索，不必等到清除成功。KNOWN 的粒子或网格为空不能导致 ABSENT。每次证据变更递增 `revision`，后验缓存与候选收益缓存按频道修订号区分。

`history` 是去除同位置重复后的有效无线电观测；完整请求和响应仍保存在 `events.jsonl`。同一位置出现矛盾结果会报错。清除失败单独保存在 `failed_clear`，不能当成无线电的 no_signal。

## 3. 正负反馈联合推断

### 3.1 正反馈几何外包

`geometry.after_measure` 对 direction 裁剪示向度扇区和 1500 米接收上限，对 near 裁剪 5 米圆；无信号不直接从这个凸多边形中扣除圆。

圆使用外接半平面近似，因此多边形是保守外包。示向度允许区间使用题目 1°、半个 0.01° 量化步长和微小数值余量。该余量刻意略保守。

### 3.2 每个位置的一致性

`beliefs.point_feasibility(point, history, cfg, failures=())` 返回：

- 必需半径下界 `lower_radius`；
- 全向是否可行及其半径上界；
- 定向是否可行及精确开闭圆周方向区间；
- 被正反馈激活、必须解释为背向的历史负记录数。

下界是 1000 米与全部正记录距离的最大值。全向要求所有负记录距离严格大于下界。定向要求所有正记录在正半平面，并且下界以内的负记录在严格背面。所有约束必须由同一个固定半径和同一个固定方向解释。

`angles.py` 的区间运算支持跨 0°、开端点、闭端点、极窄区间及孤立可行端点。不能用固定角度栅格的“无命中”代替这些硬约束。

### 3.3 自适应网格

`grid.build_grid(polygon, history, failures, cfg)` 返回 N×4 的闭包方格、裁剪后的单元多边形、面积及两类假设的保守可行标记。

流程为：正外包与粗方格相交 → 距离上下界和放宽方向区间筛选 → 对保留大格继续细分 → 达到最小边长或单元预算即保留。

中心点不可行不删除整个方格。整格排除必须使用最小／最大距离、半对角线造成的方向放宽等充分条件。单元预算只能改变精度，不能截断剩余可行部分。与失败清除圆完全相容的整格才允许删除；边界格保留。

### 3.4 后验近似

`beliefs.rebuild(channel, cfg)` 返回并缓存：

```python
belief.cells                 # N × 4, xmin,ymin,xmax,ymax
belief.cell_polygons         # 保守保留单元与正外包的交集
belief.cell_areas             # 面积
belief.particles             # K × 2, 位置
belief.weights               # K, 和为1
belief.radii                 # K, 对应固定接收半径
belief.orientations          # K, 弧度；全向可为NaN
belief.directional           # K, bool
belief.area
belief.diagnostics
```

位置先验按单元面积加权；类型先验由 `prior_directional` 控制；方向先验均匀；半径先验在 [1000,1500] 均匀。给定方向后，用前向负记录限制半径上界。概率质量包含可行方向宽度和半径区间长度。用于存在性检验的最小半径没有被当作真实半径估计。

压缩样本时按类型分层，避免采样条数偏差改变全向／定向总后验质量。未采到位置的保守单元仍保留。若所有样本退化，候选与有限清除机制仍使用保守几何，不报告无目标。

未知频道不建立昂贵的完整位置／方向后验，使用下一节的全负空间证据；这是当前实现有意保留的计算简化。

## 4. 连续覆盖与未知频道排查

`coverage.load_verified_layout` 不仅相信 JSON 中的 certified 字段。它重新检查：

1. 每个证书方格的所用站点距所有顶点严格小于 1000 米。
2. 这些站点的凸包包含整个方格。
3. 方格在四叉划分中完整覆盖半径 1800 米任务圆，不能删除证书叶子后仍通过。

每个未知频道单独保存负记录与 1848 个方格的已排除标记。新负反馈到来时，找出完全位于该观察点 1000 米内、且尚未排除的方格；对全部历史负观察点重新计算近点凸包。如果凸包包含方格，则方格任何目标及任何 180° 朝向都会与负记录矛盾，安全排除。

非固定站点的负反馈也参与这套判断。只有整个圆的所有方格都得到证据，UNKNOWN 才能变成 ABSENT。

`Coverage.next_station(world)` 优先 O→I→M→E；同层在尚未完成的站点中选最近站并锁定，完成其必要频道后才重新选择。每个站点只安排 UNKNOWN 且尚未检查的频道。站点坐标不能随意偏移；偏移后原证书不再自动成立。

## 5. 候选、收益与模板

### 候选生成

`Candidates.positions` 汇总当前点、正反馈外包中心、负反馈安全单元联合外包中心、near 点、后验均值与不同位置模态、第二问提供器候选及横向／中间观察点。

位置最终按 `candidate_limit` 截断。该上限限制评分计算，不删除可行假设或覆盖任务。普通机会操作只考虑 `local_radius_m` 内的位置。

### 收益预测

`gains.received_mask` 用样本的位置、半径和辐射半平面预测能否收到信号。

`measurement_forecast` 对 no_signal、near 和不同示向度结果分别筛选同一组联合样本。正读数误差采用有界均匀先验的三节点积分，示向度代表数由 `prediction_outcomes` 限制。

定位收益是后验位置加权均方根半径的期望相对缩小，单个分支的负改善截为 0。它是收益排序的近似指标，不是保守直径证明，也不是第二问最坏直径最优值。

探索收益是仍未被负证据排除的证书格中，位于候选点 1000 米位置脚印内的面积权重乘 0.5。它是低成本排序代理，没有声称等于完整联合后验下的实际发现概率。

清除收益为 20 米内的后验概率。若全部保守单元顶点到清除点均在 20 米内，则改用几何保证概率 1；概率较低的普通尝试由 `clear_min_probability` 过滤。有限兜底不受该概率阈值阻止。

加权收益为探索 1、定位 4、清除 8，除以期望耗时。移动计一次；measure 需要时收取换频道 1 秒并改变 radio；clear 成功 5 秒、失败 3 秒，不切换测向机频道。

### 同点模板

`templates.four` 生成主操作、主操作＋已知频道、主操作＋未知频道、主操作＋两者。每个组合内同一频道最多一次，主操作先执行，默认最多三条。

Scheduler 保存真实待执行队列。每条执行前检查位置、频道状态、重复观测、清除概率、剩余预算及新的收益。主清除成功后合法同点附加操作仍可使用原剩余预算；发现外圈新目标会立即转入锁定清除并重置不适用队列。

## 6. 长期推进与绕路预算

圆心初扫和外圈巡检按必要频道逐项执行。内部层、近边界层之间允许局部高收益模板。

对锁定站点 a、当前位置 p 和候选位置 q，机会操作的移动绕路量为：

$$
\Delta T_{\mathrm{move}}=\frac{\|p-q\|+\|q-a\|-\|p-a\|}{5}.
$$

选择模板时预留所有机会操作的最坏服务时间与保守频道切换开销。执行后利用真实虚拟时间减去向站点取得的进度收费；预算跨每步重规划累计，不重置。仅切换到新站点时获得新的阶段预算。

内部两层完成后，将剩余已知源逐个清除再进外圈。外圈发现目标后立即锁定，保留站点／频道账本，清除后恢复尚未完成的巡检。锁定阶段主操作不使用站点绕路预算，其他频道同点操作另受 30 秒累计预算限制。

## 7. 有限清除兜底与结束

一个锁定目标的主操作次数达到 `max_refine_actions`，或没有合适普通候选时，建立覆盖当前保守正反馈多边形的方格中心序列。

默认边长 24 米，因此格内任意点到中心不超过：

$$
\frac{24}{\sqrt{2}}\approx16.97<20.
$$

依次尝试这些中心可覆盖完整保守区域，且与辐射方向无关。序列和游标保存在 Channel，不能每步从头重新生成。仅当整格被新几何排除或被以前失败清除圆完全覆盖时跳过。完整序列用尽仍未找到已知源属于模型／数值矛盾，报告失败，不能伪造成功。

完成条件为：所有频道均 CLEARED 或 ABSENT；或已经清除 16 个不同频道（达到题目源数上限）。发现数量达到下限 10 不是结束依据，扫描外圈没有新信号本身也不是结束依据。

## 9. 调参和扩展边界

| 字段或模块 | 作用 | 调整时必须保留的条件 |
|---|---|---|
| grid_initial_m / grid_min_m / grid_max_cells | 网格精度与计算量 | 预算截断不能删除未证伪单元 |
| particle_count / orientation_samples | 后验概率近似精度 | 不能用空样本证明不存在 |
| prior_directional | 类型先验 | 只影响概率层，不强行删除另一类型 |
| candidate_limit / prediction_outcomes | 动作与读数预测计算量 | 必要覆盖任务不能因候选上限丢失 |
| detour_budget_s | 局部利用与全局推进平衡 | 每站累计，不能每步重置 |
| finish_extra_budget_s | 锁定时顺带操作开销 | 不得阻止主目标最终清除 |
| weight_explore / weight_refine / weight_clear | 三类收益偏好 | 完成判据与证书不随权重放松 |
| clear_min_probability | 低成本清除试错倾向 | 几何保证及有限兜底应可执行 |
| max_refine_actions | 普通定位与兜底的切换 | 次数有限，且游标持续保存 |
| fallback_spacing_m | 清除覆盖密度 | 半对角必须严格小于20米 |
| assets / coverage.py | 检查站布局与负反馈证据 | 新布局必须重新提供连续覆盖证书 |
| q2_provider | 第二问算法替换 | 最終仍评价收不到信号的可能性 |

当前版本未加入动态权重、多步前瞻、未知频道完整联合后验或全局路径最优器。这些可以作为后续独立实验，不能在论文中写成已经实现。

## 10. 实验与回放数据

`tools/run_acceptance.py` 固定运行 15 局。实验管理器单独创建合法场景，启动原自制模拟器 HTTP 服务，再启动不含真值参数的策略子进程。原场景和完整动作记录在策略结束后保存。

每局的 `actions.jsonl` 是实际轨迹与操作记录；`strategy3/events.jsonl` 另含候选动作、收益预测、阶段、累计预算、推断诊断和状态。后续可视化应读取这些日志，不需要重跑环境。

`strategy_cpu_time_s` 为策略进程 CPU 消耗；`real_time_s` 为模拟器从 enter 到结束的墙钟；`strategy_real_runtime_s` 包含策略初始化和退出等。实验源码指纹涵盖所有策略 Python 模块与覆盖资产，保证15局未在中途换实现。
