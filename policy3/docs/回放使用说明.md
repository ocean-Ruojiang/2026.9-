# Policy3 的 15 局交互回放

双击 policy3 目录中的 `open_replay.cmd`，使用浏览器打开回放。也可直接用 Edge 或 Chrome 打开 `results/acceptance_15_20260913/trajectory_viewer.html`。请勿打开 tools 目录中的同名文件，那是没有数据的界面模板。

本次完整导入 15 局，不抽样；数据直接来自已经完成的模拟器日志，没有重新运行实验。生成的 HTML 内嵌全部数据，可离线使用。

- 顶部选择测试局、频道与测量反馈类型。
- 勾选移动轨迹、检测、清除成功或失败；筛选只影响操作标记，移动轨迹仍保持真实先后顺序。
- 拖动底部进度条，或点击“从头播放”，逐步查看行动与清除进度。
- 点击操作列表或图中标记查看坐标、时间、反馈、决策阶段、操作模板和可用绕路预算（日志有记录时）。
- “检查站”显示本次采用的 O、I、M、E 布局；显示规划站点不代表该时刻已经到访。
- “叠加真实目标”和“真实发射范围”均为事后分析真值，不是策略当时掌握的信息。全向范围显示为圆，定向范围显示为半圆，建议筛选单频道查看。已清除源的范围仍保留用于复盘。
- “显示示向线”画出记录的观测方向，线长仅用于显示，不代表估计距离。
- 可导出当前画布为 PNG。播放按操作步推进，不按虚拟时间等速，也不插值模拟移动过程。

在 policy3 目录中重新生成（仅需 Python 标准库）：

```powershell
python tools/visualize.py --input results/acceptance_15_20260913 --output results/acceptance_15_20260913/trajectory_viewer.html
```

可通过 `--case 11 --channel 4 --operations move,measure,clear_success` 设置打开时的默认显示。输入也可以是一个 case 目录。导出器与界面模板均独立放在 tools 中，不依赖 policy2，不修改策略和模拟器代码或原始日志。
